# Project Rules & Guidelines

- **Tech Stack**: Vite + vanilla JS + Three.js 0.160 only. No other libraries unless explicitly asked.
- **Assets**: Primitives only (no external 3D models or textures).
- **Architecture**: One system per file. Keep files organized under appropriate `src/` modules.
- **Workflow & Reporting**: After every task, update `TASKS.md` and write a report of 5 lines maximum.
- **Scope Discipline**: Never rewrite files you were not asked to touch.
- **Code Quality**: Keep the code simple, readable, and well-commented.
- **Required Reading**: `docs/LORE.md` and `docs/GDD.md` are required reading before developing new features.
