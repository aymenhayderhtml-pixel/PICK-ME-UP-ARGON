# Archive — Historical Reports

These are **one-time audit, QA and implementation reports** kept for the record. They
describe a specific task at a specific point in time; they are **not** kept in sync with
the code and several contain numbers that have since changed (for example the town
layout coordinates in `TOWN_PLACEMENT_REPORT.md` predate the Space-Time Rift move).

Do not treat anything in here as current behaviour. The live reference is
[`../CODEMAP.md`](../CODEMAP.md) for the code and [`../../README.md`](../../README.md)
for the project.
